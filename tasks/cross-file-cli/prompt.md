要求：

1. `parseArgs(argv)` 返回 `{ flags, words }`：
   - `--name` 形式收进 `flags`（**去掉** 前缀 `--`）；

   - 其余收进 `words`，保持原顺序。
2. `cli.mjs` 只负责渲染：`words` 用空格连起来；`flags` 含 `shout` 时整体转大写；最后输出一行。
3. 让 `node --test` 全部通过；不要改测试与 `src/parse.mjs` 之外的东西。
4. 做完自己跑一遍测试，把真实输出贴进回答。
